# camlaur
A rewrite Alad's [aurutils](https://github.com/aurutils/aurutils) in Ocaml and ysh from the [oils project](https://oils.pub/). Ysh allows us to use modules instead
of a log of the IPC that aurutils does. Ocaml is used
when the error handling would be more cumbersome in shell.
Mostly an experiment in writing small Ocaml and ysh programs
to learn but hopefully it'll eventually become usable.
No documentation beyond this readme is available.
